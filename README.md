# TUTORIO applets

Interactive pages for learning complex numbers. Each page is a single self-contained HTML file: no installs and no internet needed once it has loaded.

## Roots on the Circle

**Open it:** https://berrystrawblue.github.io/tutorio-applets/

Step through the roots of complex numbers on the Argand plane.

- **z^n = 1** (n = 1 to 8): lengths give r = 1; the angle window (0 ≤ θ < 2π makes 0 ≤ nθ < 2nπ, which holds exactly n whole turns: 0, 2π, ..., 2(n − 1)π); one root powered round to 1; all n roots; the regular polygon; conjugate pairs in −π < θ ≤ π; the formula z = cis(2πk/n).
- **z^n = w**: r = ⁿ√ρ; the angle window (nθ = ω + 2πk, exactly n values in the window); the first root at ω/n; the roots of 1 turned and stretched; conjugate pairs only when w is real; the formula.

Keys: Space or → next step, ← back, 1 to 8 choose n, U and W switch views, P power walk, L angle range, F full screen. Click any root to watch its powers.

To use it offline, download `index.html` and double click it.
